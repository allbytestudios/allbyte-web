The game plays with four input setups, **full keyboard**, **keyboard + mouse**, **mouse only**, or **mobile touch game pad**. On desktop you can switch between keyboard and mouse any time just by using the other. **Full keyboard**, **keyboard + mouse**, and **mobile gamepad** are the primary, well-tested controls; the point-and-click methods, **mouse only** and **touch**, are experimental and only lightly tested so far.

## Full Keyboard
Play with two hands controller-style: **WASD** for movement, and **O K L ;** are the four action buttons and mirror WASD's layout like a controller's four face buttons.

- **L**: Confirm / Interact / Attack
- **;**: Cancel / Back / Run
- **K**: Menu
- **O**: toggle the scene-exit markers or combat log

## Keyboard + Mouse
**WASD** still moves, and the mouse
- **Left-click**: confirm / interact (same as **✕ Cross**)
- **Right-click**: Cancel / Back / Run
- **Two modes, auto-switching:** moving the mouse switches to mouse mode (a feather cursor appears); pressing any
  **WASD** switches back. *Note, only mouse **movement** flips the mode, a click never does.*

## Mobile: touch-pad
On a phone (landscape or portrait) the game draws an on-screen controller, a **d-pad** on the left and the four **face buttons** on the right:

- **D-pad**: move and navigate menus.
- **✕ Cross** *(bottom)*, Confirm / Interact
- **○ Circle** *(right)*, Cancel / Back / Run
- **☐ Square** *(left)*, Menu
- **△ Triangle** *(top)*: toggle scene-exit markers or combat log.

## Mouse only / Touch  *(experimental)*
You can play with the mouse alone or a touch screen the same point-and-click

- **Left-click**: click to move, and interact with menus combat hud, etc.

> **💡 Experimental, minimal testing.** Touch and full mouse-only play is new and has only been lightly tested. Keyboard or keyboard + mouse remain the smoothest way to play on desktop.
